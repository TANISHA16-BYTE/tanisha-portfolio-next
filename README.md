# Tanisha Jain — Developer Portfolio

A personal developer portfolio built with Next.js, React, TypeScript and Tailwind CSS.

## Featured Projects
- The Red Pen — Brand governance and content review platform.
- TrueVoice — Content verification and creator-reviewer workflow platform.
- Student Task Manager — Flask-based task management application.

## Tech Stack
Next.js, React, TypeScript and Tailwind CSS.

## Run Locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production Build
```bash
npm run build
npm start
```
